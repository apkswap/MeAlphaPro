# Security Policy

## Supported versions

Security fixes are developed against the latest version on the `main` branch. Users should install releases published from this repository and verify their SHA-256 checksums.

## Reporting a vulnerability

Please do not disclose vulnerabilities in public issues or discussions.

Report suspected vulnerabilities privately to the repository owner through GitHub's **Report a vulnerability** feature on the Security tab (Private vulnerability reporting), if enabled. Include:
- affected release, platform, and version;
- steps to reproduce and expected impact;
- proof-of-concept details that do not expose real user data.

Please allow a reasonable period for investigation and a coordinated fix before public disclosure.

## Sensitive data

Never attach real financial records, Dropbox access/refresh tokens, passwords, signing keys, keystores, or personal data to an issue or pull request. Revoke and rotate any credential that may have been exposed.
